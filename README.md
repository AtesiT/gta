# NIGHT STREETS

Небольшая пиксельная игра с видом сверху в духе классических GTA: одна городская
улица ночью, человечек, которым можно бегать, прохожие, машины и свет фонарей.

## Запуск

Любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

(ES-модули не работают с `file://`, поэтому нужен именно сервер.)

## Управление

| Клавиши | Действие |
| --- | --- |
| `WASD` / стрелки | идти |
| `Shift` | бежать (тратится выносливость) |
| `E` | взаимодействие — кафе, книжный, дели, лоток с едой |
| `H` | подсказки |
| тап/мышь | на телефоне: тяни палец по левой половине — движение, тап справа — действие |

## Что внутри

- `index.html`, `css/style.css` — оболочка и экран запуска.
- `js/main.js` — цикл игры, ввод, камера, HUD-состояние.
- `js/game.js` — рендерер: низкое разрешение + целочисленный апскейл, сортировка
  спрайтов по «линии земли», ночное освещение.
- `js/hud.js` — портрет, HP/SP, деньги, мини-карта.
- `js/entities.js` — игрок, прохожие, трафик, коллизии.
- `js/art/*` — вся графика рисуется процедурно в рантайме: кирпичные фасады,
  витрины, пожарные лестницы, парк с фонтаном, фонари, деревья, персонажи
  (`js/art/roofs.js` — крыши южной стороны: парапет со светлым отливом, жёлоб,
  плоскость крыши с заплатками и лужами, водонапорки, будки выхода, трубы,
  слуховые окна, кабели и неоновые вывески на самой крыше).

Асеты из `example/` — референс настроения, в игре не используются: вся графика
оригинальная и генерируется кодом.

## Dev-инструменты

`tools/` — вспомогательные скрипты для разработки, браузер им не нужен:

| Скрипт | Что делает |
| --- | --- |
| `node tools/test.mjs` | прогон игры без браузера: 37 проверок (коллизии, камера, `E`, ресайз, рендер, скорость) |
| `node tools/shots.mjs` | кадры игры в PNG (`SHOTS=имя:x:y`) |
| `node tools/bench.mjs` | замер времени кадра |
| `node tools/cropworld.mjs x y w h scale name` | крупный кроп любой части карты |
| `node tools/zoom.mjs`, `tools/zoom1.mjs` | контактные листы спрайтов персонажа |
| `node tools/headless.mjs N` | N кадров реального игрового цикла |
| `node tools/intro-shot.mjs` | перерисовать картинку экрана запуска |

Скрипты требуют `npm i` внутри `tools/` (там единственная зависимость —
`@napi-rs/canvas`). Для самой игры они не нужны.
