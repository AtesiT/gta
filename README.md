# NIGHT STREETS

Небольшая пиксельная игра с видом сверху в духе классических GTA: одна городская
улица ночью, человечек, которым можно бегать, прохожие, машины и свет фонарей.

## Запуск

Любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

(ES-модули не работают с `file://`, поэтому нужен именно сервер.)

## Управление

| Клавиши | Действие |
| --- | --- |
| `WASD` / стрелки | идти |
| `Shift` | бежать (тратится выносливость) |
| `E` | взаимодействие — кафе, книжный, дели, лоток с едой |
| `H` | подсказки |
| тап/мышь | на телефоне: тяни палец по левой половине — движение, тап справа — действие |

## Что внутри

- `index.html`, `css/style.css` — оболочка и экран запуска.
- `js/main.js` — цикл игры, ввод, камера, HUD-состояние.
- `js/game.js` — рендерер: низкое разрешение + целочисленный апскейл, сортировка
  спрайтов по «линии земли», ночное освещение.
- `js/hud.js` — портрет, HP/SP, деньги, мини-карта.
- `js/entities.js` — игрок, прохожие, трафик, коллизии.
- `js/art/*` — вся графика рисуется процедурно в рантайме (кирпичные фасады,
  витрины, пожарные лестницы, крыши с водонапорками, фонари, деревья, персонажи).

Асеты из `example/` — референс настроения, в игре не используются: вся графика
оригинальная и генерируется кодом.

## Dev-инструменты

`tools/` — вспомогательные скрипты, которые рендерят кадры в PNG без браузера
(`node tools/shots.mjs`). Они не нужны для самой игры.
