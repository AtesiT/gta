# Этап 1 — арт-дирекшн

Десять визуальных систем для top-down криминальной игры. Один и тот же кадр
(дорога, тротуар, крыши, машина, персонаж) отрисован десятью разными способами.

## Как посмотреть

- `styles.html` — интерактивная доска: 10 превью 200×200 + палитры + технический
  разбор по каждому стилю (раскрывается по клику).
- `preview/contact-sheet.png` — все десять в одной сетке (1×).
- `preview/contact-sheet-2x.png` — та же сетка в удвоенном размере.
- `preview/NN-<id>.png` — отдельные превью.

Открыть локально: просто открыть `design/styles.html` в браузере
(внешних зависимостей нет, всё рисуется на Canvas).

## Служебное

`tools/preview.js` — dev-утилита: рендерит те же сцены в PNG без браузера
(мини-реализация Canvas2D + запись PNG). Нужна только для проверки превью.

```bash
node design/tools/preview.js
```

`archive/previous-directions/` — наработки прошлых итераций, в текущей ветке
не используются.
