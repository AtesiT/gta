# Этап 1 — арт-дирекшн

Десять визуальных систем для top-down криминальной игры. Один и тот же квартал
(дорога, тротуары, крыши, машина, два персонажа) отрисован десятью разными способами.

## Масштаб

| Что | Размер |
|-----|--------|
| Сцена | 480 × 480 px = 15 × 15 тайлов |
| Тайл | 32 × 32 px |
| Машина | 72 × 114 px |
| Игрок | 30 × 48 px |
| Прохожий | 32 × 52 px |
| Спрайт-лист | 4 кадра ходьбы + машина + дерево + гидрант + урна |

Клик по кадру на странице открывает его в 1 : 1. Чекбокс «сетка тайлов 32×32»
накладывает разбивку на сцену.

## Цветокорр (грейд-пасс)

Поверх всех сцен работает общий LUT-грейд — логика «как в Stardew Valley»:

| Пресет | Что делает |
|--------|-----------|
| **Цветокорр «Долина»** (по умолчанию) | тёплый день: холодные синие тени, кремовые света, +20 % насыщенности, мягкий контраст, нижний порог яркости (никакой черноты) |
| Мягкое утро | матовая пастель: приподнятые тени, молочные света, низкий контраст |
| Тёплый вечер | золотой час: больше янтаря в светах, тени глубже и синее |
| Без грейда | исходные палитры стилей |

Грейд считается один раз на кадр: контраст → гамма → поканальные gain/lift → насыщенность →
сплит-тонирование (синий в тенях / тёплый в светах) → нижний порог. Пары «до/после» —
`preview/compare-before-after.png`, листы по каждому пресету — `preview/contact-sheet-valley.png`,
`-morning.png`, `-dusk.png`, полные карточки — в `preview/<пресет>/`.

Стиль **11 «Тёплый квартал»** — бонус: палитра собрана сразу под этот грейд (тёплый камень,
кирпич, горчица, зелень, пыльно-синий), поэтому грейд на нём применяется мягче (×0.85).

## Как посмотреть

- `styles.html` — интерактивная доска: сцена, тайлсет с подписями, спрайт-лист,
  палитра и раскрывающийся технический разбор по каждому стилю.
- `preview/contact-sheet.png` — все десять сцен в одной сетке.
- `preview/contact-sheet-2x.png` — то же в удвоенном размере.
- `preview/NN-<id>.png` — сцена целиком.
- `preview/NN-<id>-card.png` — сцена + тайлсет + спрайты одним листом.

Открыть локально: просто открыть `design/styles.html` в браузере
(внешних зависимостей нет, всё рисуется на Canvas).

## Служебное

`tools/preview.js` — dev-утилита: рендерит те же сцены в PNG без браузера
(мини-реализация Canvas2D + запись PNG). Нужна только для проверки превью.

```bash
node design/tools/preview.js
```

`archive/previous-directions/` — наработки прошлых итераций, в текущей ветке
не используются.
